# Nanyi CRM 安全与质量加固计划

更新日期：2026-09-16

本文档记录项目审查发现的问题、实施顺序和验收标准。功能里程碑完成不等同于生产就绪；以下事项完成前，系统仅建议用于开发、演示或受控内测环境。

## 阶段一：生产配置与鉴权边界

- [x] 移除当前配置中的远程数据库和 Redis 凭据，改用本地开发默认值与环境变量。
- [x] 生产配置显式设置 `app.env: prod`，确保 Swagger 在生产环境关闭。
- [x] 限制高权限角色分配：非超级管理员不得分配 `admin`、`superAdmin`。
- [x] 保护内置角色和账号，避免被非超级管理员修改或删除。
- [x] 全局角色、菜单和接口治理能力仅允许平台管理员访问。
- [x] Refresh Token 使用 Redis 原子轮换、哈希键名，并区分 access/refresh token 类型。
- [x] 修复失败登录日志缺少租户 ID 的问题。
- [x] 生产 JWT 和初始化管理员密码无效时快速失败。
- [x] 增加基于 IP 和用户名的登录失败限流。

注意：曾经提交过的远程凭据仍需在对应服务端立即轮换；是否重写 Git 历史应由仓库维护者结合协作情况决定。

验收标准：

- 租户用户即使拥有用户管理权限，也无法为账号绑定平台管理员角色。
- 生产镜像中 `/swagger/index.html` 不可访问。
- 同一个 Refresh Token 并发刷新时最多一个请求成功。
- 仓库中不存在可用的远程服务凭据。

## 阶段二：租户与数据一致性

- [x] CRM 子数据的 `tenant_id` 从目标客户继承，不从操作者身份推导。
- [x] 客户、商机、合同归属人必须与业务数据属于同一租户。
- [x] 部门父子关系必须属于同一租户，并禁止形成任意层级循环。
- [x] 创建接口正确保留显式的停用、隐藏状态。
- [x] 合同编号通过活动记录生成列增加数据库级租户内唯一约束，软删除历史不占用编号。
- [x] 删除客户前检查关联商机和合同；删除租户时检查全部 CRM 数据。
- [x] 创建或修改首要联系人时自动取消同客户的其他首要联系人。
- [x] 对客户等级、业务状态、合同状态流转和合同日期关系进行严格校验。
- [x] 新增 `000005_tenant_integrity` 迁移，补齐租户字段和唯一索引。
- [ ] 将生产环境完全切换为版本化迁移并停用 AutoMigrate。

验收标准：

- 任意 CRM 关联记录的租户与客户租户一致。
- 并发创建相同合同编号时数据库只允许一条成功。
- 部门树无法跨租户挂接，也无法形成环。
- 使用纯 SQL migrations 初始化后，表结构与模型定义一致。

## 阶段三：前端会话与交互

- [x] Profile 加载失败时清理登录状态，避免登录页和首页循环跳转。
- [x] 动态路由的 KeepAlive 名称与页面组件名称保持一致。
- [x] 路由查询参数变化时同步刷新页面筛选条件。
- [x] 将 Vue、Axios、Element Plus 等依赖拆分为独立 vendor chunk。
- [ ] 逐步将令牌从长期 localStorage 存储迁移到更安全的会话方案。

验收标准：

- 后端不可用或 Profile 请求失败时停留在登录页，不发生重定向循环。
- 标签页切换后列表筛选和未提交表单状态能够按预期保留。
- 从不同客户进入跟进页面时，客户筛选条件及时更新。

## 阶段四：运行、审计与测试

- [x] 操作日志记录业务响应码，而不是只记录 HTTP 状态码。
- [x] Dashboard 每条聚合查询都检查并返回数据库错误。
- [x] 增加 HTTP 读写超时、优雅停机和数据库/Redis 连接关闭。
- [x] 配置可信代理、CORS 白名单和常用安全响应头。
- [x] 为后端和前端容器增加健康检查，并修正文档中的健康检查路径。
- [x] 后端容器使用非 root 用户运行。
- [x] 增加登录限流。
- [ ] 增加异常登录告警和集中监控。
- [ ] 补充基于真实 MySQL/Redis 的租户越权、角色提权、Token 轮换和删除关联集成测试。
- [ ] 增加前端单元测试及关键流程端到端测试。

验收标准：

- `go test ./...`、`go vet ./...`、`pnpm build` 全部通过。
- 多租户和权限相关的回归测试不依赖人工检查。
- 容器停止时能够在超时范围内完成连接关闭和请求收尾。
- 健康检查能够区分应用存活与数据库、Redis 不可用。

## 后续演进

- 金额字段从 `float64` 迁移到定点 decimal 或整数分。
- 为高冲突业务记录增加乐观锁。
- 将自动播种改为明确、可审计的数据迁移。
- 将 AutoMigrate 限制在开发环境，生产环境只执行版本化迁移。

- 后端新增 JWT 类型校验、Refresh Token 原子轮换、登录失败限流和高权限角色保护。
- CRM 写入改为继承客户租户，并补充负责人、关联对象、状态及日期校验。
- 新增租户完整性迁移和数据库级合同编号唯一索引。
- 前端修复会话失败循环、动态页面缓存和查询参数同步问题。
- 生产配置关闭 Swagger，容器增加健康检查、安全响应头和非 root 运行用户。
- 新增 JWT、生产配置、CORS 和合同状态流转单元测试。
